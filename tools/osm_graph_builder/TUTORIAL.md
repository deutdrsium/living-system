# 教程：用 OpenStreetMap 生成你的常住区域地图

这份教程手把手教你把自己常待的地方（学校、小区、公司附近）做成一张"常住区域地图"，给角色在生活里使用。整个过程不需要会编程，只要能照着复制粘贴命令就行。

做完以后你会得到一个 `.json` 文件，里面记录了这片区域里的地点（宿舍、教学楼、食堂、便利店……）、连接它们的路，以及每段路大概要走多久。

> 想了解工具的全部参数和技术细节，请看同目录的 [README.md](README.md)。这份教程只讲怎么用。

---

## 整体流程

1. **准备**：装好 Python，打开命令窗口。
2. **确定范围**：在地图上找到你的区域，记下中心点的经纬度。
3. **获取地图数据**：从 OpenStreetMap 下载这片区域的数据文件。
4. **生成地图**：运行一条命令，得到第一版地图文件。
5. **微调**：在浏览器里打开编辑器，补名字、连路、改时间，导出新版本。
6. **保管好文件**，以后需要时再更新。

第一次做大约需要 30 分钟到 1 小时，主要花在第 5 步的微调上。

---

## 第 1 步：准备工作

### 1.1 安装 Python

如果你的电脑还没有 Python：

1. 打开 <https://www.python.org/downloads/>，下载最新的 Python 3 安装包。
2. 运行安装包。**安装界面最下方的 "Add python.exe to PATH" 记得勾上**，然后点 "Install Now"。

装好以后可以检查一下：打开命令窗口（见下一小节），输入

```
py -3 --version
```

看到类似 `Python 3.13.x` 就说明装好了。

### 1.2 在项目文件夹里打开命令窗口

后面所有命令都要在**项目根目录**里运行，也就是能看到 `tools`、`plugins`、`docs` 这几个文件夹的那一层。

Windows 上最简单的方法：

1. 用资源管理器打开项目根目录。
2. 在文件夹空白处按住 **Shift 键再点右键**，选择"在终端中打开"（或"在此处打开 PowerShell 窗口"）。

也可以点一下资源管理器顶部的地址栏，把里面的路径删掉，输入 `cmd` 后回车。

> **关于命令的小提示**
> - 教程里的每条命令都是**一整行**，复制时请完整复制，不要自己换行。
> - 文件路径如果有空格或中文，请用英文双引号把它括起来，比如 `"D:\我的地图\home-v1.json"`。

## 第 2 步：确定你的区域

工具需要知道"从哪儿到哪儿"。最简单的说法是：**一个中心点 + 一个半径**。

### 2.1 找到中心点的经纬度

1. 打开 OpenStreetMap 官网：<https://www.openstreetmap.org/>
2. 搜索或拖动地图，找到你的区域（比如你的学校）。
3. 在你想作为中心的地方**点右键**，选"显示地址"。左侧会出现这个位置的坐标，形如 `31.0234, 121.4321`。前一个是**纬度**，后一个是**经度**。

另一个办法：把地图移到中心位置后看浏览器地址栏，网址末尾形如 `#map=17/31.0234/121.4321`，其中第二、三个数字就是纬度和经度。

> **⚠️ 不要从高德、百度、腾讯地图上抄坐标。**
> 国内地图 App 显示的坐标经过了偏移处理，跟 OpenStreetMap 用的坐标对不上，会差出几百米。请一律在 OpenStreetMap 官网上取坐标。

### 2.2 选一个半径

半径用米表示。实际取的是以中心点为中心、边长为两倍半径的**正方形**。

| 你的区域 | 建议半径 |
| --- | --- |
| 一个小区、一条街 | 300–500 米 |
| 一所普通大学的校园 | 800–1500 米 |
| 校园 + 周边商圈 | 1500–2500 米 |

范围越大，生成的地点越多，后面要检查和整理的东西也越多。**建议第一次小一点**，不够再扩大。

---

## 第 3 步：获取地图数据

下面三种方式选一种就行。**大多数人用方式 A 就够了。**

### 方式 A（推荐）：在 OpenStreetMap 官网直接导出

适合：区域不太大（一个校园或小区）。不需要额外安装任何东西。

1. 在 <https://www.openstreetmap.org/> 上把地图移到你的区域，并缩放到**刚好能把整个区域框进屏幕**。
2. 点页面顶部的 **"导出"（Export）**。
3. 左侧会显示当前视野的范围。点 **"手动选择不同的区域"** 可以拖出一个框，把你的区域框住。框要比你在第 2 步定的范围**大一些**，不能小。
4. 点蓝色的 **"导出"** 按钮，浏览器会下载一个名为 `map.osm` 的文件。
5. 把这个文件移到一个好找的地方，比如 `D:\我的地图\map.osm`。

如果网站提示区域太大、不能直接导出，说明你框的范围太大了。可以把框缩小一点，或者改用方式 B。

### 方式 B：下载整个省份或国家的数据（Geofabrik）

适合：区域比较大，或者方式 A 导不出来。下载的文件比较大，而且要多装一个小组件。

**下载数据：**

1. 打开 Geofabrik 下载站：<https://download.geofabrik.de/>
2. 依次点进你所在的大洲和国家，比如 **Asia（亚洲）→ China（中国）**。如果国家下面还有更小的地区（省、市），就选你所在的那一个，文件会小很多。
3. 下载后缀为 **`.osm.pbf`** 的那个文件，比如 `china-latest.osm.pbf`。整个国家的文件可能超过 1 GB，需要一点时间。

这份文件只需要下载一次。工具会从里面只取出你指定的那一小块，之后就不再需要原文件了。

**安装读取组件（只需做一次）：**

在项目根目录的命令窗口里依次运行这两行：

```
py -3 -m venv .venv
```

```
.venv\Scripts\python.exe -m pip install -r tools\osm_graph_builder\requirements-pbf.txt
```

第一行在项目里建一个独立的小环境，第二行把组件装进去，不会影响你电脑上的其他程序。

> 用方式 B 时，第 4 步命令开头的 `py -3` 要换成 `.venv\Scripts\python.exe`，下面会再提醒一次。
> 不要直接用 `py -3 -m pip install ...` 安装，那样会装进全局环境。

### 方式 C：让工具自己联网下载（最后的选择）

适合：前两种都不方便。工具会向 OpenStreetMap 的公共查询服务发**一次**请求，把你的区域下载下来。

请注意：

- 这是志愿者免费提供的公共服务，**请不要反复使用**。下载成功后数据会保存在你电脑上，以后不需要再联网。
- 区域最大约 25 平方公里，相当于半径 2500 米。
- 如果下载失败，工具会要求你**等一段时间**（至少 1 分钟，服务器要求更久就更久）才能再试，换个范围也一样。这是为了不给服务器添麻烦，不是出错了。

用法见第 4 步的"方式 C"命令。

## 第 4 步：生成第一版地图

先想好两样东西：

- **地图名字**（`--graph-id`）：给这张图起个英文名，比如 `my-campus`。以后更新同一个地方的地图时，名字要保持不变。
- **保存位置**（`--output`）：生成的文件放在哪里、叫什么，比如 `D:\我的地图\my-campus-v1.json`。

然后按你在第 3 步选的方式运行对应的命令。下面的命令里，请把**坐标、半径、文件路径**换成你自己的。

**方式 A（官网导出的 map.osm）：**

```
py -3 -m tools.osm_graph_builder --source "D:\我的地图\map.osm" --center 31.0234 121.4321 --radius-m 1000 --graph-id my-campus --output "D:\我的地图\my-campus-v1.json"
```

**方式 B（Geofabrik 的 .osm.pbf）：** 注意开头不同。

```
.venv\Scripts\python.exe -m tools.osm_graph_builder --source "D:\下载\china-latest.osm.pbf" --center 31.0234 121.4321 --radius-m 1000 --graph-id my-campus --output "D:\我的地图\my-campus-v1.json"
```

如果下载的是整个国家的大文件，这一步可能要跑几分钟，请耐心等它结束。

**方式 C（让工具联网下载一次）：**

```
py -3 -m tools.osm_graph_builder --overpass --center 31.0234 121.4321 --radius-m 1000 --graph-id my-campus --output "D:\我的地图\my-campus-v1.json"
```

### 怎样算成功

窗口里会打印一大段文字，开头是 `"output"`，后面跟着你的文件路径。打开 `D:\我的地图\` 能看到 `my-campus-v1.json`，就说明生成好了。

这段输出里有一部分叫 `"report"`，是这张图的"体检报告"。不用现在细看，第 5 步的编辑器里也能看到，到时再解释。

### 同一块区域再生成一次

工具会把取出来的数据**存在你电脑上**（用户文件夹下的 `.cache\osm-graph-builder`）。以后对**同一个中心点和半径**再生成时，可以省掉 `--source` 或 `--overpass`，工具会直接用存好的数据，不联网：

```
py -3 -m tools.osm_graph_builder --center 31.0234 121.4321 --radius-m 1000 --graph-id my-campus --output "D:\我的地图\my-campus-v1-again.json"
```

如果你换了新下载的数据文件，想让工具读新文件而不是存好的旧数据，在命令末尾加上 `--refresh`。

如果这块区域是在"彩色底图"功能出现之前生成过的，存好的旧数据里没有绿地、水面这些彩色区域。这时也要加上 `--source "你的数据文件"` 和 `--refresh` 重新读一次文件，才能看到完整的彩色底图（见 5.1 节）。如果当初是用方式 C 联网下载的、手头没有数据文件，就改加 `--overpass --refresh`。这会**重新联网下载一次**，同样受"失败后要等一段时间"的限制。

## 第 5 步：在编辑器里微调

OpenStreetMap 是志愿者画的，数据不可能完美：有的楼没名字，有的楼跟路没连上，有的路其实走不通。编辑器就是用来修这些的。

### 5.1 打开编辑器

1. 在资源管理器里找到项目里的 `tools\osm_graph_builder\editor.html`，**双击**，用 Chrome 或 Edge 打开。
2. 点页面上方的文件选择框，选中你刚生成的 `my-campus-v1.json`。
3. 地图就会显示出来。底下是一张彩色的"参考底图"：绿色是草地、公园和树林，浅蓝是湖和河，棕灰色块是楼，白色、黄色、橙色的线是道路，还标着地名、楼名和路名（放大后会显示更多名字）。**蓝色的圆点和蓝线**才是你可以编辑的地点和路。

底图只用来帮你认路，不会变成角色能走的路。如果觉得底图太花，可以在第二排工具栏取消"显示彩色底图"，或者把"底图不透明度"拖小一些。

编辑器完全在你自己的电脑上运行，默认不联网，也不会上传你的文件。（唯一的例外是你自己打开的"在线 OSM 底图"开关，见 5.7 节。）

> **看不到绿地和水面？** 如果你的地图文件是在这个功能出现之前生成的，里面没有彩色区域，编辑器会在顶部提示。按第 4 步重新生成一次，并在命令末尾加上 `--refresh`。有数据文件时，让工具重新读取它，例如：
> ```
> py -3 -m tools.osm_graph_builder --source "D:\我的地图\map.osm" --refresh --center 31.0234 121.4321 --radius-m 1000 --graph-id my-campus --previous "D:\我的地图\my-campus-v2.json" --output "D:\我的地图\my-campus-v3.json"
> ```
> 如果当初用的是方式 C（让工具联网下载）、没有数据文件，把 `--source "..."` 换成 `--overpass`：
> ```
> py -3 -m tools.osm_graph_builder --overpass --refresh --center 31.0234 121.4321 --radius-m 1000 --graph-id my-campus --previous "D:\我的地图\my-campus-v2.json" --output "D:\我的地图\my-campus-v3.json"
> ```
> 这会**重新联网请求一次**，请不要反复运行；如果失败，要按提示等待一段时间（冷却期）才能再试。
>
> 这样做不会改动你已有的地点和路，只是把彩色底图补上。

**如果打开文件时提示"当前浏览器不支持本地摘要"**，换一种方式打开：

1. 在项目根目录的命令窗口运行：
   ```
   py -3 -m tools.osm_graph_builder --serve-editor
   ```
2. 窗口会显示 `Local graph editor: http://127.0.0.1:8765/`。在浏览器里打开这个网址。
3. 用完后回到命令窗口，按 **Ctrl+C** 关掉它。

### 5.2 看懂"生成报告"

页面下方有一栏**"生成报告与编辑历史"**，点一下展开。里面是一段程序格式的文字，用的是英文名称，列出来的是 `osm:node/10`、`osm:way/22` 这样的编号。每个编号对应一个地点或一段路，你可以在页面上的**"数据表"**里找到同一个编号，点它就会在地图上选中。

最值得关注的是这几项：

| 报告里的名称 | 是什么意思 | 你可以怎么做 |
| --- | --- | --- |
| `isolated_nodes` | 这些地点跟任何路都没连上，角色"走不过去" | 用"连接两个节点"把它和最近的路口连起来 |
| `unnamed_places` | 这些地点没有名字 | 选中它，填上名字（如"三号宿舍楼"） |
| `missing_access`、`missing_opening_information` | 不知道这里能不能随便进、几点开门 | 对重要的地方（宿舍、图书馆、食堂）补上 |
| `dropped_items` | 在范围边缘被截断、或者本来就不能走人的路 | 一般不用管 |
| `edges_needing_review` | 合并地点时重复的路被并成了一条，时间取了最短的 | 选中这条路，看看"预计秒数"是否合理 |

每次修改后报告会自动更新，可以用它来确认还剩多少没处理。

**孤立的地点很常见**，因为地图上的楼和路本来就是分开画的。你不需要把每栋楼都连上，**只连角色会去的地方**就够了。

### 5.3 常用操作

页面上方的工具栏：

- **选择 / 拖动节点**：点一个地点或一条路，右侧会显示它的信息；按住拖动可以挪位置。
- **框选（拖出矩形）**：在地图上按住鼠标拖出一个框，框里的地点都会被选中。勾着"框选包含道路"时，两头都在框里的路也会被选中。详见 5.4 节。
- **平移地图**、**放大**、**缩小**、**适应范围**：调整视野。
- **点击新增节点**：在地图上点一下，新增一个地点（比如地图上没有的快递站）。
- **连接两个节点**：先后点两个地点，在它们之间加一条路。
- **合并所选节点到另一节点**：两个点其实是同一个地方时，把它们合成一个（先点要去掉的，再点要保留的）。很多个点合成一个请用 5.5 节的方法。
- **撤销上次修改**：退回一步。

右侧"地点与道路"面板，选中东西后可以修改：

- 地点：**名称**、**地点类型**、**区域**（比如"东区"）、**活动能力**（这里能做什么，多个用逗号分开，如 `吃饭,自习`）、**楼层 / 房间**、**门禁**、**开放规则**。
- 路：**预计秒数**（走完这段要多少秒）、**方向**（双向，或只能从起点到终点）、**通行状态**（启用或关闭）。

改完记得点 **"保存修改"**。不需要的东西选中后点 **"删除所选项"**。一条路中间要加一个地点时，用 **"拆分所选边"**。

**关于时间：** 工具按正常步行速度估算每段路要走多久，楼梯、小路会算得慢一些。这只是估计。如果你知道某段路实际要走更久（比如要等红绿灯、爬坡），直接改"预计秒数"。拖动地点后，相连的路会保留原来的秒数，请顺手检查一下是否还合理。

### 5.4 一次选中很多东西

有时你想一次处理一大片，比如把一堆用不到的小路删掉。

- **框选**：工具栏的模式选"框选（拖出矩形）"，然后在地图上按住鼠标左键拖出一个框，松开。框里的地点（和两头都在框里的路）会变成**黄底黑框**。
- **追加**：按住 **Shift** 再拖一个框，新框里的东西会加到已选的里面。
- **单独加减一个**：按住 **Ctrl**（Mac 上是 **Cmd**）点一个地点或一条路，已选的会取消，没选的会加上。
- **全部取消**：按键盘左上角的 **Esc**，或点侧栏的"清除选择"。
- **用表格选**：展开页面下方的"数据表"，每行最左边有一个小方框，勾上就是选中。在筛选框里输入"宿舍"之类的字，再点"勾选全部筛选结果"，可以一次选中所有名字里带"宿舍"的地点。

地图右上角和右侧会显示"已选 12 个地点、5 条路"这样的数量。选了不止一样东西时，右侧会出现"批量操作"：

- **删除已选**：把选中的地点和路一起删掉，连在这些地点上的路和出入口也会删掉。要删的东西超过 3 个时会先问你一遍，告诉你一共删多少。删除算**一次**修改，点一次"撤销上次修改"就能全部恢复。
- **合并为一个地点…**：见下一节。

> 框选模式下拖动鼠标是画框，不会移动地图。要挪动地图，先把模式换回"选择"或"平移地图"。

### 5.5 把一片宿舍楼合并成一个地点

OpenStreetMap 经常把每栋宿舍楼单独画出来，生成的地图里就有"宿舍一号楼""宿舍二号楼"……一大堆地点。如果对角色来说它们就是"示例宿舍"一个地方，可以合并成一个：

1. 把地图放大到能看清这片宿舍楼。
2. 模式选 **"框选（拖出矩形）"**。
3. 从宿舍区的一个角按住鼠标，拖到对角松开，把这些楼都框进去。漏了的楼，按住 **Ctrl** 点一下加进来；多框进来的（比如旁边的食堂），按住 **Ctrl** 点一下去掉。
   - 也可以用数据表：筛选"宿舍"，点"勾选全部筛选结果"。
4. 看右侧的数量对不对，然后点 **"合并为一个地点…"**。
5. 选择合并后的地点：
   - **保留已选中的一个地点**：从下拉框里挑一栋楼（比如名字最像的那栋），其他楼都并到它身上。
   - **在选区中心新建地点**：在所有楼的正中间新建一个地点，填上**名称**（例如"示例宿舍"）和**类型**（例如 `dormitory`）。
6. 下面会写出合并的结果，例如"将把 6 个地点并入新地点「示例宿舍」：改接 4 条路，删除内部路 3 条……"。确认没问题，点 **"确认合并"**。

合并时工具会自动处理这些事：

- 原来连到这些楼的路，都改连到合并后的地点。
- 两头都在这片宿舍里的小路（楼与楼之间的连接）会删掉，因为它们已经没有意义了。
- 如果合并后两个地方之间出现了好几条重复的路，只留下**时间最短**的一条，并在报告的 `edges_needing_review` 里提醒你复核它的时间。
- 被合并掉的楼会作为"已删除"记在历史里，以后用新的 OpenStreetMap 数据重新生成时，它们**不会再冒出来**。

合并也只算**一次**修改，不满意就点"撤销上次修改"整体恢复。

### 5.6 标出出入口：校门、地铁站口、公交站

角色去城外（比如坐地铁去博物馆）时，**每一趟都从某个"出入口"离开你的地图，回来时也从某个出入口进来**。你的地图里如果没有合适的出入口，角色就没法坐公交或地铁出门。

所以请把这些地方标成出入口：

- **校门**、小区大门：走路出门的地方。
- **地铁站口**：在地图上找到离站口最近的那个地点（没有就用"点击新增节点"加一个，再用"连接两个节点"把它连到路上）。
- **公交站**：同样，选中站台旁边的地点。

怎么标：

1. 在地图上点选那个地点。
2. 右侧"编辑地点"下面（"保存修改"按钮的下方）有一栏 **"出入口"**，点 **"设为出入口"**。
3. 下面会出现三个勾选框：**步行**、**公交**、**地铁**。勾上这里能接上的交通方式。刚设好时只勾着"步行"。
   - 校门一般只勾"步行"。
   - 地铁站口勾"地铁"（站口也能走路进出的话，"步行"也留着）。
   - 公交站勾"公交"。
   - 一个地方既有地铁口又有公交站，可以都勾上。
4. 至少要留一个勾，最后一个勾是灰色的、去不掉。如果这里其实不是出入口，点 **"取消出入口"**。

**每一步（设为出入口、勾一个框、去掉一个框、取消出入口）都算一次修改**，点"撤销上次修改"就能退回这一步。勾选框改完立刻生效，不用为它点"保存修改"。如果你刚在上面改了名称等内容还没保存，勾选不会把它们冲掉，但那些内容仍要点"保存修改"才算数，页面也会提醒你。

把两个出入口合并成一个地点（5.3、5.5 节的合并）后，它们算作**同一个出入口**，勾选框显示两边加起来的交通方式。之后第一次改勾选时，工具会把它们整理成一条记录（尽量保留 OpenStreetMap 原有的那个门）。

标好以后：

- 地图上出入口的地点外面会多一个**橙色方框**。
- 右侧"出入口"列表会列出所有出入口和它们接的交通方式，例如"南门 连接：步行 · OSM"。"OSM"表示是 OpenStreetMap 原本就标了的门，"手工"表示你自己设置或改过的。点名字可以在地图上选中它。
- 页面下方数据表的"预计时间 / 出入口"一列，和"生成报告与编辑历史"里的 `gateways`，也会写出每个出入口的交通方式。

工具第一次生成地图时，只会把 OpenStreetMap 上标了"门"或"入口"的地方自动设为出入口，而且只勾"步行"。**地铁和公交需要你自己勾上**，工具不会猜。

你设的、改的、取消的出入口，以后重新生成地图（第 6 步）时都会保留：你取消的门不会再冒出来，你勾上的"地铁"也不会被改回去。

### 5.7 在线 OSM 底图（可选）

如果你想和真正的 OpenStreetMap 地图对照（比如确认某栋楼的位置），可以打开第二排工具栏的 **"在线 OSM 底图"** 开关。

**打开前请了解它的隐私含义：**

- 打开后，浏览器会从 OpenStreetMap 的官方服务器下载**你当前正在看的这块区域**的地图图片。服务器因此会知道你在看哪里（大致位置和放大程度），以及你的网络地址。地图文件本身、你改的名字和内容**不会**发出去。
- 这个服务器是志愿者维护的免费服务，只允许少量使用。请只在需要对照时短暂打开，不要长时间大范围地拖来拖去。
- 打开时会先弹出说明，你点"确定"才会开始加载。开启期间地图左上角有一条黄色提示，右下角显示"© OpenStreetMap contributors"。
- 这个开关**不会被记住**，每次打开编辑器都是关的。

这个开关只有用 5.1 节里的 `--serve-editor` 方式打开编辑器时才能用；直接双击 `editor.html` 打开时它是灰色的，旁边会告诉你怎么启动。打开在线底图后，彩色底图仍然叠在上面，可以取消"显示彩色底图"只看在线地图，或把不透明度调低对照。

### 5.8 设置谁能走、什么时候开放

以前的“门禁”和“开放规则”文字仍能查看、修改。现在在它们下方还有“结构化门禁与时间”：把你已经确认的规则填在这里，角色才能按资格和时间判断。不要把“可能开放”“需另外授权”“只在考试周开放”直接改成全天开放；没有把握就保留“尚未解析”或“未知”。

1. 在地图或数据表只选一个地点或一条路。
2. 看“当前解析”：`unparsed` 表示文字尚不能按规则判断；`unknown` 表示没有信息。生成报告的 `unparsed_access`、`unparsed_opening` 也会列出这些项。
3. 在“通行资格”选公众、校内成员、学生、教职工、住户或关闭。“沿用原文字”保留原判断；学生和教职工都算校内成员，但学生不能自动进入教职工专用区。选住户时，再填一个稳定的区域或宿舍 ID，例如 `dorm-east`。角色设置里需要有完全对应的 `resident_of:dorm-east`。
4. 已确认开放时间时，选择“已确认时间窗口”，填时区，例如 `Asia/Shanghai`。窗口每行填“星期 开始 结束”，星期一到星期日对应 `0` 到 `6`。例如工作日上午八点到下午六点，填 `0,1,2,3,4 08:00 18:00`；周末另起一行 `5,6 09:00 17:00`。每天全天开放填 `0,1,2,3,4,5,6 00:00 24:00`；跨夜填 `0,1,2,3,4,5,6 22:00 06:00`。选择已确认时间但不填任何窗口，表示一直关闭。
5. 点一次“保存修改”，门禁和时间作为同一次修改保存，点一次撤销可全部恢复；导出后再用 `--previous` 更新也会保留。地点和道路都按同样方式操作。

OSM 的 `yes`、`permissive` 表示公众可用；`no` 表示关闭；`private` 必须由你明确配置资格，不能因为角色是学生就自动通过。可以在“私有区域 ID”填 `dorm-east`，让这一项使用该区域的资格映射。`destination` 和无法完整理解的长段说明仍保留为尚未解析；系统不会从一大段说明里挑出时间数字就认定开放。

角色设置在生活插件配置里：`graph_access_enabled` 默认关闭；开启后 `graph_access_credentials` 默认空，可填 `student`、`staff`、`campus_member`、`resident_of:dorm-east`。`graph_private_credentials` 默认是空对象，例子 `{"my-campus":"student","my-campus/dorm-east":"resident_of:dorm-east"}` 表示整张图的 private 要求学生，宿舍区域则要求对应住户。这些资格须由显式运行宿主接入，不会从角色聊天内容猜测；没有接入宿主时，保存配置本身不会启动出行。

启用后，未知开放时间不会默认变成开放，未解析文字也不会静默放行。确实只想在模拟中先按假设试路线时，才把 `treat_unparsed_access_as` 和/或 `treat_unknown_opening_as` 从默认 `blocked` 改为 `allowed`：路线会明确写出哪些地点或道路用了假设，并显示 `needs_review`（需要复核）。关闭、缺资格和没有 private 映射仍然不能走。这是待复核的模拟假设，不是确认了真实通行规则。

生成器默认仍把 private 道路关掉。若明确采用资格判断，可在生成命令加 `--structured-access`，保留 private 道路供资格检查；`no` 仍然关闭。已经关掉的旧边要先核实，再在编辑器把“通行状态”改为启用，资格不会自动替你开启关闭的道路。

### 5.9 导出新版本

改好之后点 **"导出新版本"**。浏览器会下载一个新文件，名字形如 `my-campus-v2.json`，版本号自动加 1。再导出一次就是 v3，以此类推。

> **⚠️ 编辑器不会自动保存。** 关掉页面前一定要先导出，否则这次的修改全部丢失。改得多的话，建议中途也导出几次。

下载的文件一般在"下载"文件夹里，建议把它移到 `D:\我的地图\`，和 v1 放在一起。**旧版本不要删**，它们就是你的修改记录。

## 第 6 步：以后怎么更新

过了一段时间，OpenStreetMap 上的数据可能更新了（新开了店、修了新路），你想用新数据重新生成，又**不想丢掉自己做过的修改**。

先按第 3 步重新下载数据，然后运行（以方式 A 为例）：

```
py -3 -m tools.osm_graph_builder --source "D:\我的地图\map-new.osm" --refresh --center 31.0234 121.4321 --radius-m 1000 --graph-id my-campus --previous "D:\我的地图\my-campus-v2.json" --output "D:\我的地图\my-campus-v3.json"
```

要点：

- `--previous` 后面填你**最新的那个手动修改版**。
- `--graph-id`、中心点、半径和上次保持一致。
- `--output` 用一个**新文件名**。工具不会覆盖已有的文件，如果你填了一个已存在的名字，它会报错让你换一个。

你手动加的、改的、删的东西都会保留，包括出入口和你勾选的交通方式。新文件生成后，用编辑器打开看一遍，确认没问题再使用。

## 生成好的地图怎么用

目前插件这边**只做好了读取和校验的部分**，管理页面上还没有导入按钮。请先把生成的文件保管好，等导入功能上线后再按页面提示导入。

导入时插件会先显示"这次和上次相比改了什么"，你确认之后才会真正保存成新版本，不会悄悄替换。

## 注意事项

- **隐私**：这个文件精确记录了你住在哪、在哪上课。**不要公开分享**，也不要上传到公开的网盘或仓库。
- **版权署名**：地图数据来自 OpenStreetMap，文件和编辑器里都保留了"© OpenStreetMap contributors"的署名，请不要删掉。
- **精度**：地图只表示大致的结构和距离，步行时间是估算值，不代表真实导航。

## 常见问题

**提示 `no matching cache; supply --source or explicitly opt in with --overpass`**
你没有提供数据文件，而这块区域之前也没生成过。请加上 `--source "你的文件路径"`（方式 A/B），或者加 `--overpass`（方式 C）。如果你之前生成过，检查中心点和半径是不是和上次完全一样。

**提示 `output exists; choose a new filename to retain history`**
`--output` 填的文件已经存在。换一个新文件名，比如把 `v1` 改成 `v2`。

**提示 `PBF requires optional tool dependency ...`**
你用的是 `.osm.pbf` 文件，但还没装读取组件，或者命令开头写成了 `py -3`。提示里给出的就是第 3 步方式 B 的做法：先运行 `py -3 -m venv .venv`，再运行 `.venv\Scripts\python.exe -m pip install -r tools\osm_graph_builder\requirements-pbf.txt`，然后把生成命令开头换成 `.venv\Scripts\python.exe`。不要用 `py -3 -m pip install` 安装，那样会装进全局环境。

**提示 `Overpass cooldown active; wait ... seconds`**
方式 C 上次没成功，需要等提示里的秒数之后再试。也可以改用方式 A 或 B，它们不受影响。

**提示区域太大（超过 25 平方公里）**
方式 C 有面积上限。请缩小半径，或者改用方式 B。

**生成出来的地点特别少，或者大部分地点都是"孤立"的**
- 检查经纬度有没有写反（纬度在前，中国大陆一般是 18–54；经度在后，一般是 73–135）。
- 检查是不是从国内地图 App 抄的坐标（见第 2 步的提醒）。
- 用方式 A 时，检查导出的框是否完整盖住了你的范围。
- 地点"孤立"本身很正常，见第 5.2 节。

**命令窗口说 `py` 不是内部或外部命令**
Python 没装好，或者安装时没勾 "Add python.exe to PATH"。重新运行 Python 安装包，选 "Modify"，勾上相应选项；或者卸载后按第 1 步重装。

**中途想停下来**
在命令窗口按 **Ctrl+C**。
