# 验收场景与实现完成标准

依赖：[公共契约](03-shared-contracts.md)。这些是后续实现需执行的场景，不是本轮已经运行通过的测试。按任务包挑选适用项，不要求文案或每次小改都跑完整模拟。

## 契约与边界

| 编号 | 输入/操作 | 应观察到 |
|---|---|---|
| B01 | 注册两个模块 owns 同一 key | 第二个拒绝，原状态不变 |
| B02 | 同角色不同会话同时开始前台活动 | 至多一个进入 running；授权上下文各自保留 |
| B03 | 新增复用执行器的活动模板 | 无需修改内核或主插件活动类型分支 |
| B04 | 宿主下游记忆消费失败后重试 | 原活动/感想不重复生成，消费者有独立状态 |
| B05 | 旧 lease 注销后新实例注册 | 旧回调不能调用新实例，调度器只存在一份 |
| B06 | 同 command_id，参数摘要不同 | 拒绝，不产生新效果 |

## 状态

| 编号 | 输入/操作 | 应观察到 |
|---|---|---|
| S01 | 相同睡眠轨迹，重启点不同 | 确定性状态一致，睡眠秒数不重复累计 |
| S02 | 跨清醒/入睡/醒来边界推进 | 每段使用正确公式，S不越界 |
| S03 | 半餐取消、半程运动取消 | 仅实际阶段效果，精力不重复扣减 |
| S04 | 重复读取页面/状态 | 不额外积分或抽情绪噪声 |
| S05 | 恒定情绪输入与多个种子 | 均值回归及波动范围符合配置模型 |
| S06 | 截止前可用时间为零 | 压力信号为不可行档，不除零/无穷 |
| S07 | 已患同类病程期间继续推进 | 不重复 onset；病程不占前台槽 |
| S08 | 旧文字状态迁到新模型 | 有明确映射/保留策略，不静默重置 |

数值验证选择有意义的容差和统计样本量，依据模型与时间尺度说明理由；不能用一次随机轨迹“看着合理”证明概率正确，也不追求不同切段的随机路径逐点完全相同。

## 跨库与离线

R01：分别在准备、宿主决定、生活提交、宿主确认、事件 ACK 前后中断。恢复后不丢原结果、不重复外部副作用，未决屏障按协议保留。
R02：离线数天后恢复，不补写未执行浏览、购买和满勤；预测状态有 estimated/assumptions。
R03：模板升级时已有 running/paused 实例，按原版本继续或显式转换，不重抽参数。
R04：切换后产生新生活数据再回退，新增记录、事件游标和去重回执均保留；不能恢复旧快照丢数据。
R05：跨会话共享身体但材料只对一会话授权，身体互斥正确且材料不泄露。

## 页面与真实集成

U01：页面展示在途、失败、unknown 与模拟来源，不只显示“成功”。
U02：管理命令权限拒绝、旧 revision 拒绝，状态不被覆盖。
U03：目标服务器上的 Pocket ID 登录及 iframe 内脚本、样式、后台读写真正可用；匿名与未授权写入仍拒绝。
U04：通过浏览器调试或标签页控制完成页面核验，不使用整个电脑控制。

平台替身通过不等于真实平台通过；本地 HTML 可打开不等于线上 iframe 可用；任务入队不等于任务执行完成。

## 多日生活验证

先选固定种子跑7天，观察睡眠、活动时长、地点连续性、余额、截止与事件积压；通过后用数个种子看30天分布。评价不要求永远不缺课或永远最优，而要求资源守恒、规则可解释、活动不过度塌缩、失败能恢复。

每次任务交付列出：适用编号、实际运行命令/环境、结果、未覆盖项和理由。不要为未执行项打勾。只有新修改或未解决疑点才扩大测试范围。
