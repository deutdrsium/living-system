# 材料来源与下游记忆

依赖：[公共契约](03-shared-contracts.md)、[执行与感想](14-execution-impressions.md)。主插件已有来源、权限与资产能力继续作为权威，不在生活侧建立平行权限系统。

## 四类来源

| 类型 | 能证明什么 | 不能据此宣称 |
|---|---|---|
| source_backed | 某版本材料/片段被实际取得或读取 | 材料描述的事件发生在角色身上 |
| simulated | 某套有版本规则生成了模拟行动或结果 | 现实世界传感器已验证发生 |
| authored | 配置者提供了角色、课程、校园等设定 | 某真实学校或人物就是如此 |
| generated | 实际生成并保存了文本、图像等产物 | 内容全部来自现实观察 |

一个 artifact 可以混合来源：模拟参观 + 真实馆藏介绍 + 生成短评。分别保存各部分的依据，不能用一个 public 标签抹掉限制。

## 内容取得与授权

活动声明输入槽；适配器取得 source_ref，再由宿主按角色、原会话、用途和受众检查。读取时、模型提交前、结果落库前按现有任务规则重新核验，不能以准备时的一次授权覆盖长时间活动。

source_ref 至少关联版本/内容摘要、片段范围、获取时间。缓存必须保留权限和撤回关系；资料更新后不把旧片段进度直接套在新版本偏移上。

LLM 输入中的网页、书籍和上传配置是材料，不是可以改变系统授权和工具行为的指令。活动配置只请求已注册能力，不得借资料文本绕过网关。

## 生活产物与记忆候选

生活保存事实与当次产物；完成事件把引用交给主插件收件箱。主插件基于相关性、受众、重复与原有记忆规则决定是否收录，保留原 artifact/event 引用。

不必把每个成功活动写进长期记忆。日记可读取当天经历；兴趣成长只消费实际新材料及其回执。重复事件不会重复增加曝光、兴趣或关系值。

即时感想不直接证明长期立场变化；反思可以提出长期变化，但仍由主插件自己的成长机制处理。角色对话可以自然叙述，内部必须能追到依据。

## 来源撤回与历史

撤回后停止未完成的材料消费；结果落稿前发现撤回则拒绝发布。已生成的感想、日记和记忆按既有来源依赖规则隐藏/失效，不能从另一个缓存恢复可见正文。

活动时间、已发生的金额等非敏感事实是否保留，按原授权与审计规则处理；不必伪造“从未发生过”。隐藏内容与取消历史事件是不同操作。

跨库结果确认前遵守现有读取屏障，不让主插件看见一份稍后会被撤销的未确认完成记录。

## 模型预算

使用主插件既有预算与任务用量。世界组件可声明任务能力、输入/输出上限、阶段调用上限与失败降级；实际 Token、失败与取消计费按真实回执记录，不能因为业务失败就当成本为零。

准备阶段只为少量入选候选请求昂贵材料。不要每 tick 让模型重新评估所有活动。缺模型预算时规则活动照常运行，需要语义消费的活动等待或换合法目标。

## 对外表达

share_candidate 不等于 send。主插件继续决定是否主动联系、选择渠道与表达方式，并复核当前受众和来源。visibility: public 只能是请求上限，最终范围是身份、上下文、来源、操作许可的交集。

当用户询问“你真的去过吗”，系统能区分模拟路线经历与外部实地验证；不能将全景浏览描绘成现实身体行动的证据。

## 验收

撤回片段不能经旧感想泄露；不同会话受众不扩大；一条完成事件重投不重复记忆/兴趣；生成图片有实际资产才算完成；仅浏览影评不会生成电影看完进度；可选分享失败不改变活动事实。
