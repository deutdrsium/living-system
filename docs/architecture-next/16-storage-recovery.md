# 持久化离线与恢复

依赖：[公共契约](03-shared-contracts.md)、[生命周期](04-kernel-lifecycle.md)。先复用现有 LifeStorage、PreparedCommands 和宿主审计，不另造一套跨库事务框架。

## 数据归属与事务

生活库保存活动、进度、预留、领域事实、当次产物引用、延迟队列、事件 outbox 与消费去重。主库保存人格、记忆、来源资产、平台任务、基础审计与宿主 inbox。

生活域内可在一个 SQLite 事务提交实例、钱包/位置/状态变更及 outbox。跨库命令必须通过现有准备、宿主决定、生活提交、宿主确认流程；两个独立 commit 不构成原子事务。外部调用不放在事务中。

每个 repository 只写自己的表；协调器可组织同库事务，但不能让模块任意执行另一模块 SQL。

## 跨库交接恢复

| 中断位置 | 恢复动作 |
|---|---|
| 只有准备记录 | 查询宿主持久决定；没有决定不能猜成功。是否撤销按现有明确恢复策略执行 |
| 宿主已决定提交，生活未落库 | 沿原命令和摘要完成幂等本地提交，不重新调用模型/平台 |
| 生活已落库，宿主未确认 | 查询原结果并完成确认，读取/后续执行遵守未决屏障 |
| 宿主已确认，事件未确认 | 重投同一 event_id；消费者去重后返回原回执 |
| 外部动作结果未知 | 查询原 operation/task；保留 unknown，不更换 id 重发 |

v2 batch 1 的本地协调回执将 decision 与 settlement 分开。显式协商 life.command.abort-own 后，仅原 owner/context 的 activity-model-complete-* 未决准备命令可申请撤销；先查宿主原决定，无决定原子决定 abort，已有 commit 只能恢复。只有 abort+confirmed 才能另起 pause 命令；unknown 保留原 ID 和屏障。授权 intent 的 v2 adapter 在 dispatch 前持久保存开始时间锚点，通过既有 request_for_replay 恢复同一 start command 的 prepare/decision/apply/confirm/ACK，queue 删除后的 inspect 不依赖 queue；不扩展 v1 同步提供方接口。完整配对、旧在途支持期限与回退见 [v2 映射](contract-v2-migration.md)。

旧文档包含开发过程中的历史描述，实施时结合当前代码与测试核查已接通部分。不能因为本规划使用“目标流程”而移除现有租约、读取屏障、来源检查或回退保护。

## 事件投递

事务内写 outbox，事务外投递；接收方先持久化 inbox/去重，再安排异步任务。ACK 丢失可以重投。承诺是至少一次投递 + 本地幂等效果，不是所有网络副作用 exactly-once。

模型与平台消费者持久化稳定任务 id，未知结果由原执行监督处理。不能在 consume_once 的同步本地回调里等待网络。失败消费者单独记录，不阻塞无关角色和消费者无限等待。

## 离线补算

默认补算连续状态与已知计时，不补造自由活动。

- 已知睡眠区间、登记病程、已经确认的路线阶段和配置收入按规则续算。
- 尚未执行的阅读、浏览、发帖、购买不生成成功回执。
- 过期课程处理为 missed/unknown 或待政策判定，不自动写满勤。
- 延迟事件到期后按业务有效性处理：包裹仍可取，过时出发提醒过期。
- 长离线区间不能假装知道每顿饭和每次睡眠。未知模式段可按显式预测策略给 estimated 状态，保留 assumptions；关键资源如余额、真实位置不能靠预测变成已确认事实。

可选“离线规则生活”作为后续独立模式：明确哪些活动可纯规则模拟、用何参数、怎样结算、怎样标来源。仍走同一生命周期与钱包账本，不由 LLM 一次补写几天日记。默认不开启。

推进按事件边界而非逐秒重放；需要小步的状态模块可批量推进。时间倒退不允许负 dt；保留 last_advanced_at，输出时钟异常并等待修正策略。

## 配置升级与在途实例

运行实例固定 template/executor/model 版本与参数摘要，新配置只影响新实例。升级前检查旧执行器能否继续恢复；不能恢复时先明确暂停与转换，不能直接删旧 handler。

领域 schema 迁移独立有版本，转换前保留可验证备份。状态模型迁移保存旧值、历史与映射，不把迁移当重置。

## 回退

回退必须包括切换后新增记录、事件游标、去重回执、任务关联与未决操作。不能只恢复旧快照而丢失新经历。使用既有迁移/回迁工具和一致性备份流程，本文不授权执行切换。

完整生活开关关闭可以停止新活动，但已决定的落库确认和必要安全恢复仍按协议处理；不能把未决命令遗弃在库中。

## 验收

按跨库五个中断点注入故障；验证原任务只执行一次、本地结果最终一致、未知操作不重发。补算后不凭空多出课程和购买；预测状态有标记；配置升级不改变在途抽样；回退保留新增事实与未决屏障。
