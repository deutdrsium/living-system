# 睡眠饥饿与精力模型

依赖：[状态系统](08-state-system.md)。这些是迁移后候选数值模型，不替换第一阶段现有规则。

## 睡眠双过程

睡眠模块维护 homeostatic pressure S、昼夜相位及睡眠片段。C 是按相位计算的昼夜项。S 与 C 分开存/算，输出困倦和建议休息信号，活动选择政策决定何时入睡。

常参数区间：

~~~text
清醒：S(t+dt) = U - (U-S(t)) * exp(-dt/tau_awake)
睡眠：S(t+dt) = L + (S(t)-L) * exp(-dt/tau_sleep)
昼夜示意：C(t) = A * cos(2π * (t-phase)/period)
~~~

dt、tau、period 使用同一时间单位。C 正负符号与困倦组合必须明确约定并通过固定时刻场景检查，不能在不同模块中各自加减。初版固定或可配置相位，不额外模拟完整光照同步机制。

困倦可先由 S 和 C 的有界映射得到；具体阈值、幅度和时间常数为模拟参数。入睡/醒来以活动真实区间为准，不能先标睡着再让精力恢复、同时仍算清醒 S。

## 睡眠债与片段

睡眠债用明确窗口内的目标睡眠与实际睡眠差推导，例如按角色配置的滚动窗口统计，具体窗口在实现时固定。它不是额外独立积分器；避免同一缺觉在 S、energy、stress 和 health 中被无意多次重罚。

保存每段开始、结束、暂停、唤醒原因、实际睡眠秒数。消息唤醒后的清醒宽限不计睡眠。午休也是睡眠片段，按同一 S 更新；是否降低夜间睡眠需求由政策决定。

取消睡眠保留已睡时长；睡眠结束事件只发一次。梦境与晨间换装由主插件消费者处理，不能睡眠重启就再发一次。

## 饥饿

首版 hunger ∈ [0,1]，值越高越饿。清醒和活动按不同负荷缓慢增加；睡眠使用较低但非任意为零的配置速率；进食事件按已吃部分降低。

进食活动先完成费用/食物可得性检查，再开始 consuming 阶段。时间没过完就取消，只应用已经发生的摄入。饱腹效应可用一次冲击 + 简单持续输入，不必先建营养素代谢系统。

饮料和正餐区分效果种类；咖啡不能永久“凭空补精力”，可作为短期困倦感受或睡眠倾向修正，保留衰减与结束时间。参数属于模拟，不作为营养建议。

## 精力

energy ∈ [0,1] 是可用于行为的功能状态，不等于困倦的简单反值。运动、行走、专注学习消耗，睡眠和休息恢复；有慢性压力/病程时通过显式输入调节恢复。

初版采用分段速率或向恢复上限指数靠近。统一活动负荷模型，避免模板 cost.energy 与状态推进重复扣除。活动只声明负荷/阶段，energy 模块按实际秒数积分。

门控读取当前精力及保守的预计消耗；执行中可在安全停靠点因低精力缩短或停止。不能把估算消耗先全部扣掉，再持续积分扣第二遍。

## 实施顺序

1. 先保持旧睡眠行为，统一睡眠区间和状态读取归属。
2. 独立验证 C/S 的清醒、整夜睡眠、午休、中途唤醒四条轨迹。
3. 接饥饿和进食，核验阶段效果。
4. 接精力和活动负荷，再逐个启用压力/健康耦合。

旧模型与新模型可以在隔离回放中比较，但生产同一 key 只能一个有效拥有者，不能两套同时写。

## 验收

连续清醒 S 单调向 U 靠近；睡眠 S 向 L 衰减且不越界；C 相位跨午夜连续；暂停睡眠不恢复该区间；半餐只记部分摄入；同一活动负荷只扣一次；重启恢复按真实已知边界计算。
