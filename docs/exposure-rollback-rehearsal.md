# 活动和浏览回退演练

`tools/rehearse_exposure_rollback.py` 接收已停止写入时分别取得的主库与生活库快照。工具先核对活动交接、宿主操作和生活事件，再对照浏览迁移清单、原会话授权、生活库的新回执及主库兴趣关联索引；未确认的命令、事件或关联冲突会使演练停止。

不指定 `--destination` 时只在内存副本演练；指定该参数时必须是不存在的新文件。工具先恢复活动账本，再恢复浏览会话及接触内容，并检查角色和会话来源、反馈外键和回迁结果。源文件不会被修改。

隔离测试使用模拟平台和独立数据库，验证了新产生的浏览记录、反馈和结果不明的互动审计。该工具不回迁日程、状态、配置或阅读运行标记，不能单独用于生产回退。
