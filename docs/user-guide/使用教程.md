# 「我会去好好生活」使用教程

如果两款插件已经配套安装并完成生活数据切换，可以直接打开「我会去好好生活」，选她的私聊窗口和角色，查看「生活总览」。第一次安装或准备升级，请先看第 2 节。文中的宿舍、教室和图编号都是示例。

## 1. 她的生活在哪里看

**日常生活。**「我会去好好生活」管理她的日程、作息、阅读、浏览和生活状态。「陪伴小屋」（`astrbot_plugin_private_companion`）继续管理聊天、角色和私聊绑定，以及日记、梦境和社交账号。浏览的安排和记录在生活页，具体的社交平台操作仍由陪伴插件按原授权处理。

**活动内核。** 它是管理一件活动何时能开始、暂停或接着做的规则。已有日常活动仍由原来的生活调度处理。新内核目前只供专门接入，例如用规则模拟整理书桌。

**钱包。** 可记录模拟预算和收支。普通安装能看到「钱包」，页面显示「钱包未启用」是正常的。模拟买饮料没有真实扣款或下单。

**阅读。** 在「阅读」查看「书架与进度」和「读书笔记」。如果待阅读的条目显示「开始阅读」，可以从那里发起。默认仍用原来的阅读方式。

**课业。** 支持手工录入学期和课表，按日期查看一节节课。到课活动需要另外接入校园路线，只记录她在模拟中的到课情况。它不登录教务系统。

**学习。** 支持记录课程大纲、作业和分段进度。一次学习可能只完成作业的一部分。模拟进度不等于提交作业或获得成绩。

**状态。** 「作息与设置」里的角色状态功能继续管理已有的睡眠和心情等设置。新状态模型可以在后台另算一份精力等变化供比较，普通安装不会拿它替换她当前的状态。

**城市出行。** 专门接入后，可以从常住区域的出口估算到固定地点的往返用时和模拟费用。离线方式使用配置好的路线，高德方式可查询公交和地铁方案。两种方式都只用于她的模拟生活。

## 2. 安装、升级和回退

### 初次接入

- `astrbot_plugin_private_companion` 和 `astrbot_plugin_good_life` 要用**同一份配套发布**里的两个包。两个插件的版本号各自编号，以发布清单里的组合为准。不要只换其中一个。
- 先在「陪伴小屋」的「账号与会话」确认 Bot 账号、角色和核心管理员窗口已绑定。需要补齐主插件的初始设置时，按主插件的快速配置步骤操作。[陪伴插件说明](../../plugins/astrbot_plugin_private_companion/README.md)
- 首次接管生活调度需要在停止写入后备份、导入和核对，并设置由生活插件接管。只安装 ZIP 不会完成切换。若日志出现「等待生活数据迁移；尚未启用调度」，请让负责迁移的人核对，不要自行改数据库标记。[存储恢复规则](../architecture-next/16-storage-recovery.md)

### 已切换服务器的配套代码升级

1. 第一次使用时，由你在自己可信的 root 会话里按手册安装审批工具。root 是服务器上有最高权限的管理员身份。每次发布由维护者先预检，选两款插件配套且自动检查全部通过的提交。[部署操作手册](../deploy-runbook.md)
2. 常规流程由维护者用 `tools/deploy_release.py --execute` 构建并上传，验证后脚本会显示审批命令。你核对发布包校验值、源码提交和两款插件的目标版本，在**自己的 root 会话**运行一次 `companion-approve release ...`（用脚本给出的完整命令）。也可以在上传前核对本地已打好的包，用同一条命令先审批。维护者再用预留名额上传同一份包，验证通过后提交作业。[发布顺序](../deploy-runbook.md#发布顺序)
3. 常规流程在审批成功后回到原脚本输入 `approved`。服务器作业会备份、成对换代码、重启并检查。一次审批只用一次，也涵盖启动检查失败后经兼容性核对的自动恢复。已启动的作业在 SSH 断线后会继续运行。重连后用 `operation <作业ID>` 查结果。还没拿到 ID 就断线时，先请维护者用 `status` 和日志核对是否已受理，别直接再提交。[中断与恢复](../deploy-runbook.md#安装超时与恢复)

### 回退代码

最近一次成功升级有问题时，可以退回升级前的配套代码，保留当前数据、配置和生活归属。用发布结果里的 `backup_id` 和当前两端版本，由你在自己的 root 会话**单独运行一次** `companion-approve rollback ...` 审批。维护者随后提交回退并查询作业。如果新功能已经启用、已有新功能记录或有未决作业，工具会阻止回退。[代码回退步骤](../deploy-runbook.md#回退)

### 恢复状态和部署密钥

- `recovering` 表示服务器正在自动恢复。等一会儿，用原作业 ID 再查，先别重发或发起回退。
- `manual-recovery` 表示需要人工处理。保留原作业记录、备份和日志，暂停新的发布和回退。由维护者核对现场，等你同意后再按手册恢复。[安装、超时与恢复](../deploy-runbook.md#安装超时与恢复)
- 发现受限部署密钥被滥用时，在自己的可信 root 会话中，从服务器受限部署账号的 `authorized_keys`（允许登录的公钥列表）里删除对应公钥。已启动的作业仍要单独核查。由 root 按手册清理未经批准、也未被作业使用的上传。[上传与备份限制](../deploy-runbook.md#上传与备份限制)

### 回到旧插件管理生活

这是另一次数据切换。先停止写入并备份现有数据，请维护者用 `tools/prepare_life_rollback.py` 准备并核对回迁结果，保留切换后新增的生活记录和防重复处理的记录，再配套切换代码和生活归属。直接恢复首次切换前的快照会丢掉这段时间的生活记录。关闭生活插件也不会让旧插件自动接手。[存储恢复规则](../architecture-next/16-storage-recovery.md)

## 3. 功能开关怎么用

下面的新功能默认关闭。已经迁移的日程、作息、阅读、浏览和原有状态照常运行。生产上每次改动开关前先确认改动内容，只改一项并记录原值。普通插件开关是在加载配置时读取的，保存后重新加载插件，再回页面确认连接。`true` 表示开，`false` 表示关。

### AstrBot 插件配置中的开关

在 AstrBot 的「我会去好好生活」插件配置中设置。表内各项均默认 `false`。

| 配置项 | 开启后的变化与条件 | 关闭后 |
| --- | --- | --- |
| `academics_enabled` | 开放手工学期、课表、大纲、作业等数据的管理入口，以及按日期查课次、查看学习进度的后台接口。需要配套插件和已授权的私聊角色。普通页面尚无课表录入表单，可请维护者协助。 | 学业入口停用，已录数据保留。单开这一项不会触发到课或学习。 |
| `grades_enabled` | 需要先开启 `academics_enabled`。课程结束后生成模拟期末成绩，角色可在相关私聊中提及教务通知。 | 停止生成新的成绩通知，已发布的成绩保留。 |
| `reading_executor_enabled` | 让新阅读改用生活插件组织选书、进度和笔记。配套陪伴插件仍须提供授权、材料和模型支持，缺少必要支持时生活服务可能连不上。 | 新阅读回到原方式。已经开始的阅读按原来的执行方式恢复。 |
| `reading_abort_own_enabled` | 给卡在提交确认阶段的新版阅读增加一种恢复方式。需要新版阅读有待处理实例，并且陪伴插件支持核对及确认中止。未能确认结果时会继续等待。 | 未决的新版中止请求保留，等再次开启后继续处理。 |

### 需要维护者接入的功能

下列名称是维护者接入时使用的设置或入口。普通 AstrBot 安装没有对应的可用开关。请维护者说明接入范围和停用方式，尤其是还有活动未结束时。

| 功能 | 配置或启用入口 | 依赖和停用 |
| --- | --- | --- |
| 活动内核 | `KernelConfig.enabled` 默认 `False` | 需要可信的宿主授权才能提议、开始活动。未接入或设回 `False` 时不安排新活动。 |
| 模拟钱包 | `register_buy_drink` 接入钱包和模拟支付，无独立插件开关 | 需要启用内核并配置币种、预留金额和支付处理。停用时请维护者先核对进行中的记账，再停止安排新活动。 |
| 模拟到课 | `academics_enabled` 加上宿主提供的 `campus` | 还需要内核、校园路径和她已确认的起点。停止新到课须由维护者停用课次接入。 |
| 模拟学习 | `academics_enabled` 加上宿主调用 `propose_study` | 需要内核、手工录入的作业和授权。有学习材料时还要通过材料读取权限检查。停用时停止安排新的学习。 |
| 后台试算状态 | `ShadowConfig.enabled` 默认 `False`。`sleep`、`hunger`、`energy` 三项也分别默认 `False` | 需要宿主提供明确的参数。启用总开关后可单独选择试算睡眠、饥饿或精力。把总开关设回 `False` 即停止试算。 |
| 离线城市出行 | `register_city` 的 `enabled` 参数默认 `False` | 需要内核、钱包、已确认的图和明确起点，以及配置好的固定地点和交通连接。设回 `False` 停止接入这个活动，由维护者核对未完成行程。 |
| 高德公交导航 | `amap_navigation_enabled` 默认 `false` | 需要城市出行已接入，再提供高德 Key 和城市编码。设回 `false` 停止新的高德请求。配置和限制见第 5 节。 |

建议先用原功能确认生活总览、日程和阅读正常。有手工课表需求时，先单独试 `academics_enabled`，确认有维护者协助录入。有新版阅读需求时，再单独试 `reading_executor_enabled`。`reading_abort_own_enabled` 留到确认宿主支持且确实需要处理停驻阅读时再开。需要专门接入的功能等维护者验收后逐项启用，高德放在最后。

## 4. 校园、课表和门禁

### 先准备一份小课表

先选一个私聊和角色，再请维护者通过已授权的后台入口录入。可以先建一个学期，填好时区和教学周，再试一门课，例如周一去「教学楼1」的课。按日期读回课次，核对上课周、放假或补课、时间和教室。补录只生成未来课次。普通安装需要接入课次执行才会模拟到课。

### 制作和修改校园图

图包是一份 JSON 文件，保存地点、相连的路、方向和步行时间。编辑器从已有图包开始。准备一份本地 OpenStreetMap（OSM，开放街图）`.osm` 文件，用生成器做第一版。Windows 上可在仓库根目录使用已有的 `.venv`，将占位符换成自己的值，边界框依次填写南、西、北、东。示例图编号 `demo-campus` 可以自选，后续更新时保持同一个编号。[生成器说明](../../tools/osm_graph_builder/README.md)

```powershell
.venv/Scripts/python.exe -m tools.osm_graph_builder --source "<本地OSM文件>" --bbox <南> <西> <北> <东> --graph-id demo-campus --output "<新图包文件>"
```

1. 在自己的电脑用浏览器打开 `tools/osm_graph_builder/editor.html`，选择生成的 `.json`。默认的离线彩色底图用建筑、绿地、水面和道路帮你辨认位置，蓝色圆点和蓝线是可编辑的地点和路。可隐藏底图或调低不透明度。如果浏览器提示无法计算本地校验值，在仓库目录运行 `.venv/Scripts/python.exe -m tools.osm_graph_builder --serve-editor`，再打开工具显示的本机地址。[本地图编辑器文件](../../tools/osm_graph_builder/editor.html)
2. 用「点击新增节点」补一个「宿舍A」，用「连接两个节点」补到「教学楼1」的路。选中道路可核对预计秒数、方向和通行状态。需要接城市交通时，点「设为出入口」，再勾选实际可用的公交或地铁。新出入口默认仅步行。
3. 用「框选」拖出矩形可选中一批地点。勾上「框选包含道路」也会选中两端都在框里的路。右侧可「合并为一个地点…」，选择保留其中一个地点或在选区中心新建，也可点「删除已选」。删除地点会连带删掉相连的路和出入口。一次撤销可恢复整次批量操作。
4. 展开「生成报告与编辑历史」，检查缺的连接、未知门禁和时间。属性改完点「保存修改」，关页前点「导出新版本」。每次导出版本号加 1。页面不自动保存，请保留导出的文件和上一版。[生成与更新教程](../../tools/osm_graph_builder/TUTORIAL.md)

生成时加 `--structured-access`，可保留 OSM 标为 `private` 的路供资格判断。标为禁止通行的路仍关闭。工具碰到无法解释的步行方向或方向条件时，会关闭受影响方向或整段路。带一般通行条件的原文会保留，启用结构化判断后默认不放行。确认图包前，请在编辑器里对照报告检查这些路、门禁和开放时间，只在核实规则后修改或启用。

### 图包确认和选图

普通 AstrBot 没有图包上传按钮或导入聊天命令。把导出的文件私下交给负责接入的维护者。接入端先用 `GraphPackageStore.preview` 预览差异，再用 `GraphPackageStore.confirm` 确认这份内容。你可以要求先看新增、移除、改名和通行变化。内容在预览后有变化就重新核对。确认的新版本须高于当前版本。

有接入时，在生活插件配置填 `academics_graph_id`，例如 `demo-campus`，并请维护者确认已把配置传给校园路线模块。默认空字符串，清空可继续用手工图。编号对应的图尚未确认时也会回到手工图（若已配置）。已有确认图时，新路线用最新确认版本，走到一半的课次保留出发时的版本。填入编号本身不会导入图包或启动课次。

### 给她设置门禁资格

1. 在编辑器里单选一个地点或路段，打开「结构化门禁与时间」。`public` 是公众可用。`campus_member` 是校内成员，学生和教职工也符合。`student` 和 `staff` 分别只认对应的学生或教职工资格。`resident_of:<area>` 只认指定区域的住户，例如 `resident_of:dorm-a`。`closed` 是明确关闭，`unknown` 是缺少信息，`unparsed` 是有原文但无法读成明确规则。
2. 填学期时区或已确认的开放时间时，用正式的 IANA 时区名，例如 `Asia/Shanghai` 或 `UTC`，图包里的时区名须用正确的大小写，不接受 `+08:00`，也不会按地图位置推断。窗口 `0,1,2,3,4 08:00 18:00` 表示工作日八点到十八点，星期一从 `0` 算起。选「已确认时间窗口」但留空窗口表示一直关闭。完成后保存并导出。
3. 接入后，用 `graph_access_enabled` 开启这套判断（默认关闭）。在 `graph_access_credentials` 填她明确拥有的资格，例如 `student` 和 `resident_of:dorm-a`。课表和角色资料不会自动授予资格。OSM 标为 `private` 时，用 `graph_private_credentials` 说明需要哪项资格，默认是 `{}`。例如 `{"demo-campus":"student","demo-campus/dorm-a":"resident_of:dorm-a"}` 表示整张图默认要求学生，`dorm-a` 区域优先要求住户。没有对应资格映射的 `private` 一律不通行。

### 待复核、出发和到课

- `treat_unparsed_access_as` 和 `treat_unknown_opening_as` 默认是 `blocked`（不放行）。确实要试模拟假设时，才把对应项设为 `allowed`。用到假设的路线会标 `needs_review`（待复核），并记录哪一处用了假设。核实规则后更新图包，把设置改回 `blocked`。已关闭的路、资格不足或缺少 `private` 映射仍然挡路。
- 接入课次执行和结构化校园路线后，系统会依门禁、开放时间和路程找可行的出发窗口。通常争取比最晚能准时到的出发时间早约 5 分钟，窗口较窄时以实际可走时间为准。开课后才到会记录迟到，只从实际模拟到达后计算出勤。
- 起点未知、走不到教室或找不到符合门禁和时间的路时，到课无法推进。请核对起点、道路方向、出发时间、门禁和图版本，再请维护者重新估算。已有确认图却搜不到路时，系统不会改从手工图绕过去。[校园路线细节](../architecture-next/11-academics.md)

## 5. 用高德估算城市出行

1. 登录高德开放平台的控制台，在应用管理创建应用、添加 Key，服务类型选 **Web服务**。Key 是用来调用高德服务的密钥。请先查看高德的额度和收费规则。
2. 请维护者确认已经把城市出行接入 AstrBot，且已配置她能走到的出口。校外地点可预先配置，或在接入地点搜索后从高德列表中选择。在服务器上打开 AstrBot 挂载的 `data` 目录下的 `config/astrbot_plugin_good_life_config.json`。把 Key 只写进服务器私有配置的 `amap_navigation_key`，不要写入聊天、Git、图包、活动或日志。
3. `amap_navigation_city_code` 填高德 `citycode`（三或四位字符串，保留开头的零）。不要填六位行政区编码。Key 和城市编码默认空。知情同意后才把 `amap_navigation_enabled` 设为 `true`，按维护者提供的方式重新加载。普通安装仅填写这三个值不会发起导航。想停用就设回 `false`。接入端在开关关闭或没有 Key 时使用离线导航。

**启用前确认隐私。** 公交规划会把两端坐标（转换成高德坐标）、城市编码、Web服务 Key 和预计出发日期时间发给高德。出入常住区时，图内端点只发送出口坐标。两个已保存的校外地点可以直接规划。高德可见请求的来源 IP，出口和目的地可能反映生活规律。

**公共地点搜索需要单独开启。** 如果维护者已接入搜索，可在知情同意后将 `amap_poi_search_enabled` 设为 `true`。搜索请求只发送公共地点名称、城市编码、服务器 Web服务 Key 及固定分页和城市限制参数。搜索不发送她的位置、出发时间、原始聊天、用户或角色标识。结果最多十项，只能从当前列表选择，选中后保存为可重复使用的校外地点。搜索无结果、限额或失败时不会生成地点。[高德适配器与隐私说明](../architecture-next/13-geography.md#amap-公交适配器用户选择默认关闭)

公交规划估算公交、地铁和步行用时。行程仍是模拟，没有实时定位、全景或途中重新导航。票价未知时不能当成免费安排出行。无路线、超时、限额或 Key 校验不通过时，本次估算可能停下。在线失败默认不会自动改用手工路线。[路线与失败处理](../architecture-next/13-geography.md)

## 6. 平时怎么检查

1. 登录 AstrBot。从左侧「扩展功能」打开「我会去好好生活」，选对「私聊窗口」和「角色」。连接处应显示「生活系统已连接」。如果跨插件链接点不开，从侧栏切换页面，或按住 Ctrl／⌘ 再点击。
2. 在「生活总览」看「此刻」「作息」「今日安排」。「此刻」和「今日安排」的「更新于」是页面上次成功读取的时间。页面可见时通常每分钟自动刷新，切到后台会暂停读取。「待确认」表示安排或任务结果仍在等确认，「已取消」是取消的活动，「失败」表示任务已报告失败。刚过午夜、日历还没读到新一天，或列表分页只读到一部分时，可能看到「日程数据不完整，空白时段暂不判断为空闲」。
3. 到「日程」查看最近的计划，例如下周的「读书时间」。如需提醒，单独在日程里安排提醒并确认权限。到「阅读」核对书架、进度和笔记，到「陪伴小屋」确认聊天仍正常、日记等原记录可读。
4. 在服务器查看容器近期日志。把占位符替换为实际容器名。重启后应能看到 AstrBot 启动，两款插件没有加载失败或禁用提示。日志中反复出现迁移等待、任务恢复错误、重复调度时，记下发生的时间，联系维护者核对。

   ```bash
   docker logs --tail 200 "<AstrBot 容器名>"
   ```

### 受限部署入口的状态和日志

按操作手册用受限 SSH 入口的 `status` 和 `logs 200` 查看。正常状态应显示容器运行、两端版本符合配套清单、执行归属为 `good_life`，生活库标记为 `ready`。`status` 若返回未完成的作业，先用原作业 ID 查询。这个入口只显示工具认识的那组开关，不能用状态列表判断所有功能是否生效。最后仍要用你自己的 Pocket ID 登录检查两个页面和原记录。[安装后验收](../deploy-runbook.md#安装后验收)

## 7. 常见问题

**页面一直「等待陪伴插件连接」？** 先确认两款插件都已启用，版本来自同一配套包，「陪伴小屋」已经就绪。再看容器日志是否在等首次数据迁移。如果刚开启了新版阅读，请维护者检查两端支持情况。之前已经开始的新版阅读仍需要这些支持。

**打开后看不到她的记录？** 先确认用有权限的账号登录，并选中原来的私聊和角色。按「刷新」再看。日程显示「尚待核对」时，用「用原请求核对」，别另外创建一条一样的记录。

**阅读一直没动？** 先看她是否在休息、有日程、材料权限是否有效，再检查阅读条目是否有可用的操作。任务显示未知或在等确认时，请先查原任务，别靠反复开始或切换开关重试。

**钱包入口已经出现，课表也说已开启？** 钱包页可以存在但显示「钱包未启用」。`academics_enabled` 只开放学业数据能力。普通页面目前没有完整的录入表单，模拟到课和学习还需要另行接入。

**高德没有方案？** 先核对服务端用的是 Web服务 Key 和 `citycode`，以及是否已配置可达出口和固定目的地。查看高德额度和服务器日志。看到票价未知或暂时不可用时，先解决配置或服务问题再重新估算。不要把 Key 或整段请求发到聊天里。

### 图包已导出，课次还是不走

请维护者核对图包是否已经确认、`academics_graph_id` 是否匹配、校园路线是否已接入，以及她的起点和门禁资格。仅仅导出图包、保存配置或录入一节课都不会安排到课。

## 8. 隐私和安全

- 只在受保护的管理页查看她的生活记录。图包、阅读材料、聊天、配置和备份都按私有数据保存，分享前先移除坐标、凭据和识别信息。关闭一个功能开关不等于删除历史数据。
- 原浏览活动可能按你在「陪伴小屋」授予的权限访问外部平台。只授予需要的权限，别把平台凭据复制到生活配置。模拟出行和上课记录不能当成现实打卡，也不要按模拟路线判断现实门禁或出行安全。
- 复制日志前先去掉私聊内容、凭据和路径等私有信息。升级、改生产开关、回退各自确认后再执行。

### 校园编辑时的联网范围

优先用本地 OSM 数据和离线底图。生成器加 `--overpass` 后，可在缓存缺失或明确加 `--refresh` 时联网请求所选范围。「在线 OSM 底图」默认关闭，只在用 `--serve-editor` 打开的本机页面可开启。开启后，地图服务会收到当前视野的大致位置、缩放级别和网络地址。图包留在本机，请保留 OSM 署名和许可。[地图工具与数据说明](../../tools/osm_graph_builder/README.md)

## 9. 这次上线后你会看到什么 / 暂时还不会发生什么

**第一次上线**只升级两款插件的代码，新功能开关保持关闭。你会看到更新后的生活总览，原有日程、作息、阅读、浏览和生活记录继续可用。新功能还没接入她正在运行的生活，暂时不会自动安排她上课、学习或出门。

**第二次上线**会接通一个完整场景：她按课表走去上课，步行到学习地点并留下你能查看的草稿和笔记，出门时接入高德公共地点搜索，并可在两个已保存的校外地点之间规划路线。相关开关及发送给高德的数据见第 5 节。
