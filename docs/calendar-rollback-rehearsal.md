# 日程回退演练（开发中）

`tools/rehearse_calendar_rollback.py` 接收主插件运行库和生活库的隔离快照。省略 `--destination` 时只做只读预检；指定一个不存在的目标文件时，工具先创建一份主库副本，再把生活库中的日程头、历史与回执写入副本并核对。它不会修改任何源快照，也不会更改执行归属标记、启用旧调度器或发送消息。

预检要求主库封存的日程与原导入快照一致；源日程的全部历史与回执必须仍存在，生活库新增版本必须连续并能在主库找到已完成的日程操作。存在未决生活命令、缺失或不一致的版本与回执、未确认的操作、源表变动或目标文件已存在时，演练停止。复制过程中出错则删除本次未完成的目标文件。旧会话角色计划已在隔离迁移中转为角色归属的，也会保留该归属及其后新增版本。

本机合成测试覆盖了产生新日程和新版本后的回退、原有去重回执、旧会话归属迁移、未决命令、丢失历史、主库操作未确认、目标文件已存在和复制中断。测试数据均为合成内容。

服务器隔离环境的同一组合测试通过；对此前的运行库和生活库演练快照生成了一份新的隔离副本，核对 6 条日程、12 个历史版本和 12 条回执。该快照没有切换后的新增数据；新增数据回退只在合成测试中验证。副本保存在受限演练目录，不进入 Git。

这只是日程回退的**离线演练**。快照需要先停止所有相关执行者并取得同一切换点的主库与生活库备份；当前工具无法证明生产已经停写，也不会处理活动、阅读、浏览、睡眠、生活事件、配置或实际执行器切换。不能直接用这份副本回退生产，完整回迁工具和线上切换流程仍需完成。
