# 阅读与睡眠运行标记迁移演练（开发中）

`tools/rehearse_runtime_markers.py` 从只读运行库快照挑选懒阅读队列、选书结果、阅读节奏、单次中断续读授权和睡眠压力修正标记，保留原键与原值并核对摘要；聊天休息回复策略留在主插件。工具不启动阅读、不消耗续读授权，也不把已安排的事情当作完成。

当前快照共 356 条相关标记已在隔离库中逐项核对，重复运行返回未变化。该快照中没有待处理的单次中断续读标记；这只是快照状态，不代表阅读任务已经完成。合成测试覆盖存在续读标记时的保留行为。

新增未分类的生活标记、无效 JSON、源数据变化或演练数据变化时，工具拒绝继续。正式切换仍须通过原任务、模型调用与来源授权检查确认是否可以续读；单纯复制标记不能授权重试。

`tools/rehearse_reading_markers_rollback.py` 可在停写后的主库与生活库快照上核对并回迁这些标记到新建的隔离主库副本。它从封存标记和已确认的导入、阅读启动、选书审计重建预期值；未决命令、手动请求或不一致的节奏、续读授权和选书结果会阻止回迁。合成测试覆盖导入后阅读、自动选书、续读及节奏被篡改；测试资料不是角色的经历。

此工具只处理运行标记，须与活动、配置、日程及其他数据的回退配合，不能独立用于生产回退。已在活动回退副本上运行时仍须使用同一停写点的生活库，并核对全部域。
