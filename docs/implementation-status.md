# 第一阶段实施状态

第一阶段把生活功能移到独立插件，并保留宿主的授权、来源管理和模型任务。

- 新插件持有日程、活动、阅读、浏览、睡眠、既有状态、巡检和迁出配置，负责唯一生活调度器；旧生活和状态定时执行器在迁移后停用。
- 状态的现有睡眠、情绪与周期计算、维护提示词和聊天状态表达由生活提供方处理；模型任务继续使用主插件监督器、授权、来源检查及用量审计。没有实现新的统一状态变量或任务插头。
- 日记、梦境、兴趣与换装通过生活事件连接主插件；跨库命令保留原操作、审计与去重，并在未完成确认时暂停相关读取。
- 迁移及新增数据后的回退工具已在隔离环境演练。若迁移后产生新数据，回退时应先停止新执行器并回迁、核对新增生活数据和去重记录。
- 新的统一状态变量、触发器、任务插头以及课业、地理、经济不属于本阶段。
