# 活动账本回退演练（开发中）

`tools/rehearse_activity_rollback.py` 在独立的主库副本中恢复生活库的活动、全部历史、材料引用和操作回执，并保留原扫描行号。省略 `--destination` 时在内存副本中演练；指定不存在的目标文件时生成隔离副本。源快照不会修改，工具不更改执行归属或启动调度器。

演练核对封存主库与原导入快照、主插件已完成的生活操作、原有历史与回执、生活库未决命令和事件处理回执。事件必须先被接收方确认，而且主库必须留有对应的完成记录；待处理或证据不一致时停止。回退副本保留删除活动后留下的旧回执，不重新创建活动。对于切换后删除的原阅读记录，只有逐行删除摘要与已确认的主库决定、管理操作和来源撤回状态一致时，才允许缺少原历史或材料；缺少证据或来源重新可用时拒绝回退。删除交接可同时取消尚未开始的关联片段；进行中或暂停的关联阅读仍需先处理执行任务。

新版本宿主事件收件箱必须逐条存在且处理完成；待处理、失败或结果未知的事件会阻止这份活动回退演练，直到完整回退流程能够保留并妥善处理这些状态。

恢复时保留生活库的历史与回执行号，同时将生活库自增序列、主库现有消费者游标和已有行号下限中较大的值写入回退副本，供配套的主插件代码继续分配行号。目标文件已存在时不覆盖；复制或核验失败会移除本次未完成的新文件。

合成测试覆盖生活库产生的新版本和回执、消费游标高于旧数据、旧删除回执、事件未确认或缺少主库回执、未决命令、切换后删除、删除摘要被改写、来源撤回、主库操作未确认和复制中断。测试数据不是角色的经历。

服务器隔离环境通过同一组测试，并使用此前的运行库及 `activity-rehearsal-v4/` 快照生成了新的隔离主库副本：389 条活动、986 个历史版本、84 条材料和 597 条回执核对一致，文件权限为 0600。这组快照没有切换后的新增经历或待处理事件；那些场景只通过合成测试验证。

新导入的文本及 EPUB 书目、首段和材料引用可参与活动回退预检；宿主原文、来源证据和管理操作必须匹配。阅读节奏、选书及续读授权须另用运行标记回退工具核对及回迁。

这仍是**离线演练**：主库和生活库快照必须来自停写后的同一切换点。工具无法证明生产已停写，也不处理配置、阅读运行标记、浏览接触、睡眠执行或其他尚未迁出的数据；旧执行器恢复、旧分页游标失效以及完整事件接收流程仍须另行实现和验证。不能直接将该副本用于生产回退。
