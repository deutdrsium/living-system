# 生活配置迁移演练（开发中）

`tools/rehearse_configuration_migration.py` 从单独的配置库快照读取 `role.life` 显式配置，要求指定配置库版本，检查源库完整性、外键、配置变更回执和字段归属。默认只读；指定隔离目录后，在新库的 `staged_configuration_*` 表中保存生活设置及其原目标、作用域和修订号，并核对内容摘要。

分类覆盖当前全部配置定义：阅读、浏览和睡眠字段进入演练表；日记、梦境和聊天休息回复策略保留主插件；总开关与日常时区两项作为共享字段复制一份初值。共享字段尚未建立单一所有者和变更同步规则，目标修订号也不能直接当作最终独立配置版本，不能据此上线。

源数据或演练表变化时拒绝覆盖；新出现未分类字段时停止。测试会比对主插件当前默认配置清单，避免新增默认字段没有归属。原配置值、目标身份、变更记录和日记风格不会打印到终端或写入仓库。
